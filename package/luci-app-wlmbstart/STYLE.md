# 界面规范

- 色彩沿用网络面板：浅色蓝色强调色、深色低对比背景，状态分别使用绿色、橙色和红色。
- 页面标题：桌面 26px、手机 24px；正文 14px，表单标签和按钮 13px，辅助说明 12px，署名 11px。
- 标准按钮和输入框：桌面至少 40px，手机至少 44px；圆角 10px。卡片圆角 12px，内边距桌面 20px、手机 16px。
- 菜单图标与功能匹配。优先使用网络面板 SVG，磁盘、电池等缺失轮廓使用相同尺度的本地图标，不使用 emoji 代替。
- 二级菜单在侧栏展开；页面选项卡可横向滚动。手机主导航为抽屉，支持关闭、遮罩、Escape 与焦点返回。
- 首页快捷入口在手机横向滑动；平板和桌面使用响应式网格。表格在所属容器内滚动，不将页面宽度撑出屏幕。
- 未知或过期状态显示不可用；电量 0% 是有效读数，外部供电不等于正在充电。
- 作者署名放右下角，固定使用继承字体、11px、正常字重。Apollo 下只保留主题的统一页脚。
- 深浅外观、系统缩放、键盘焦点和减少动态效果设置均需保留。

预览和模拟测试不能替代浏览器对具体第三方插件的排版检查。开发时至少检查 360、390、768、1024、1440px 视口，包含菜单、表单、长文本、表格、弹窗及登录页。
