# CPE 首页规范

1. 信号：运营商、制式、信号评分及 RSRP / RSRQ / SINR；明确区分无线信号与当前上网接口。
2. 设备信息：CPU / 内存用环形图表示，模组温度和设备温度分别展示；电池收纳为紧凑入口，运行时间作为次要信息。
3. 常用功能：紧凑横向入口，手机可左右滑动，不堆叠为长列表；仅展示当前账号可访问的功能。
4. 实时网速与流量：下载、上传颜色和单位一致；累计流量注明接口或已记录时段，不冒充运营商整月用量。
5. 历史网速：按实际时间定位，缺失时段断开，不补零；切换接口、重启、时钟回退时清理不兼容序列。当前浏览器最多保留一小时，不冒充全天持久历史。
6. 网络连接：LAN、WAN 和蜂窝接口，显示真实地址与 netifd 状态。

首页自带浅色和深色样式，跟随宿主的外观标记或系统偏好。宿主可通过 Apollo 提供的可选 `--luci-ui-*` 变量统一字号、间距和配色。无此变量时，首页使用自己的尺寸与配色，并按实际内容宽度调整布局。只读 Rust 快照是数据来源，首页不主动发送 AT 命令。

没有有效数据时显示未读取，不用零值替代。0% CPU、零速率和有效的 0% 电量可以正常显示。模组温度使用自身时间戳，不能用设备温度代替。
