# Apollo 界面规范

- 主题服务于通用 OpenWrt / ImmortalWrt，首页单独面向 CPE；不在主题中写入拨号或电源控制逻辑。
- 使用网络面板的蓝色与深浅配色。正文、表单和按钮默认 14px，1600px 起为 15px。桌面标题为 26–28px，手机为 24px，页脚署名为 11px。
- 一级导航使用 24px SVG 图标，普通项灰色，当前页及所属分组蓝色。二级菜单只显示文字。无法识别的第三方顶级菜单不猜图标。
- 原生网口、网桥、无线等设备图标使用 Lucide 的 24px 画布和统一线宽。仅替换已识别的 LuCI 图标路径，保留第三方应用的 Logo、标题和行为。
- 接口名称条取 LuCI 提供的防火墙区域色，深色外观压低底色亮度。设备连接状态仍由 LuCI 原生状态文本和图标样式表达。
- 标准控件桌面 40px、手机 44px，表格行内操作可以更紧凑。卡片圆角桌面 16px、手机 14px，内边距桌面 20–26px、手机 16px。
- 页面选项和分组标签栏统一使用一层圆角边框，选中项为蓝色。弹窗内部通过分组标题、留白和浅色控件建立层级，不重复堆叠分区边框。
- 统一 CJK 系统字体回退；进度条数值置于条形上方并保持可见。输入框与成组按钮之间留 10px，组内按钮至少间隔 8px。
- 菜单展开收起只过渡列表高度，耗时 220ms，切换方向时从当前高度接续。标签内容切换 200ms，弹窗进入 220ms。动效遵循系统的减少动画偏好。
- 表格在所属区域内横向滚动；原生下拉、动态列表、校验提示、确认按钮与键盘操作保持可用。
- 手机采用抽屉导航，保留遮罩、Escape、焦点返回和安全区域。深浅外观、键盘焦点和减少动画设置均需支持。
- 通用路由器没有电池支持时隐藏电池入口；读数缺失或过期时不显示假电量。外部供电不等于正在充电。
- 作者署名统一位于页脚右侧，继承字体、11px、正常字重。独立应用可选用 `--luci-ui-*` 颜色、字体、宽度和间距变量，并通过 `--luci-ui-app-credit` 避免重复署名。

真机布局至少检查 360、390、768、1024、1440px，涵盖菜单、接口、无线、系统表单、弹窗及常用第三方页面。布局检查不能代替真实网络操作测试。
