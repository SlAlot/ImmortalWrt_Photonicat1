# 光影猫电源服务

入口：**系统 → 光影猫管理**，或点击顶部电量按钮。详情默认展开；查看状态不会改变策略。

| 模式 | 行为 |
| --- | --- |
| 手动（默认） | 关闭 UPS 与每日计划 |
| 车载 / UPS | 来电自动开机后，断电延时关机，恢复供电取消；按键开机不启用倒计时 |
| 每日定时 | 按设备本地时间设置每日开关机，修改时区后重启再设置 |

保存会替换原计划，并要求确认。保留配置升级后请核对当前模式。

## 实现与状态

- 使用官方内核驱动、对应一代设备树及公开内核接口后台，来源见[官方电源方案](../../docs/OFFICIAL-SOURCE-COMPARISON.md)。
- 内核维护心跳、看门狗、RTC 和关机握手；后台只开放电源接口，不干预 QModem、模组 GPIO 或网络。
- 默认电压参数为 0，保留 MCU 默认保护。不加入独立充电开关，不降低温度或低电保护。
- 旧出厂配置逐字匹配时才迁移并备份；用户自定义值保持原样。
- 状态读取失败或过期时禁止保存，多步保存失败时尝试恢复并回读；禁止第二个控制者或裸 UART 回退。
- 每日计划由本地时间转换为 MCU UTC，界面保留本地输入。

电量按电压估算，界面显示外部供电 / 电池供电；官方一代接口未提供独立充电电流与电池温度，不填造读数。主板温度单独显示。

已验证真机启动、状态和三种模式保存、读回及互斥切换。持续充放电、断电倒计时和定时唤醒还需结合实际供电场景验证。
