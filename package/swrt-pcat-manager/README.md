# SWRT 光影猫一代电源服务

用户入口：系统 → 光影猫管理，也可点击顶部电量状态进入。只查看状态不会修改策略；电池详情默认展开，
选择手动、车载 / UPS 或每日定时模式后保存并确认。全新安装默认手动模式，
保留旧配置时可能继续沿用已有计划。电源控制仍为实验性功能。

上游：光影猫官方 `photonicat/rockchip_rk3568_pcat_manager`，`v1` 分支固定提交
`6f16e4ab4fbba220af932e02e5ef8f1a63f4bafd`。源码包 SHA256 写入 Makefile 与锁文件。
构建保留官方源文件及许可文件，不引入第三方光影猫电源插件。

构建配置编译官方 `main.c`、`pmu-manager.c`、`controller.c` 和只读模组功耗识别；删除拨号初始化和
非电源 Socket 命令，不编译 `modem-manager.c`，服务始终通过 `--distro` 禁用网络检测线程。
MCU 心跳、看门狗、串口帧格式、校验和、硬件定时命令及正常系统关机握手保留官方实现。

本地适配：

- 单一 MCU 服务；替换设备默认 `pcat-mgr`，构建配置、包冲突和成品检查阻止旧服务（含 `pcat-manager-v1`）及 `kmod-photonicat-pm` 同时占用串口。板级准备检查三层内核配置，发布前另查最终内核配置；运行时发现 `/dev/pcat-pm-ctl` 则拒绝裸串口后台启动。
- 仅从 USB sysfs 识别模组功耗类型，不占用 AT 端口，不操作 rfkill 或模组 GPIO。
  保留官方 `v1` 的电压保护与估算曲线选择；RM500U（`2c7c:0900`）使用 5G 配置，
  默认 `AutoShutdownVoltage5G=3600`。此项是低电压保护，不是充电开关；旧配置不会被强制覆盖。
- Socket 仅 root 可访问，LuCI 经细分 rpcd ACL 调用；不向网页开放任意命令。
- 电池报告超过 15 秒未刷新或串口离线时，状态视为无效，不允许保存策略。
- 电压无效、报告过期时不执行 UPS 自动关机，串口断开清除布防状态；重连后需再次观察到外部供电。
- 供电来源切换和 MCU 请求关机时记录原因与电压，保留原有应答和关机流程，便于区分低电保护与策略关机。
- UPS 需先观察到有效外部供电再开始断电监测；仅用电池手动开机不会直接进入关机倒计时。
- 普通服务停止先用官方 SIGUSR1 禁用看门狗，再停止；系统 shutdown 保留原关机／重启路径。
- 异常退出后等待 1 秒重启，避开与官方 5 秒看门狗等待相同的恢复竞态；持续故障仍可能触发硬件复位。
- `swrt-power` 是独立编写的 C 客户端，使用官方 NUL 分隔 JSON Socket 协议。
- 客户端限制数据范围、超时与响应大小；保存前验证数据与策略版本，保存后回读。
- 多步骤写入失败时尝试恢复原策略并回读确认；无法确认恢复会明确报错。
- 服务显式使用 OpenWrt `/etc/TZ`；每日计划保存前核对时区及系统时间，运行期间更改时区需重启。
- 页面轮询保留正在编辑的参数；失联后清除旧策略状态并禁止保存，恢复后重新读取。
- 现有电量显示的光影猫一代分支改读同一服务，避免旧 Go/FUSE 接口造成无效电量。

未增加 MCU 固件升级、充电电压调整或网络控制接口。无配置时沿用官方手动默认值；
已存在的官方 userdata 配置按原格式保留。自动测试使用模拟 Socket，不能证明实机唤醒或断电安全。

一代的 `on-battery` 由外部电压判断，不是充电电流测量。客户端以 `external_power` 表示
供电来源，`charging` 返回 `null`（无法确定）；顶部状态只显示“外部供电 / 电池供电”。
电量也是电压估算，不能仅凭百分比判断是否充进电。机身充电灯呼吸表示充电、常亮表示充满。
一代官方 MCU 协议没有独立充电开关；二代的充电上限命令不能用于一代，也不通过改动
充电电压、满电阈值或温度保护来模拟开关。

这里使用的公开旧 v1 后台与当前官方系统的 `pcat-manager 2.0` 不同，不能只改串口路径混用两套协议所有权。
当前官方构建树的公开范围及辅助电源修正见[官方源码对照](../../docs/OFFICIAL-SOURCE-COMPARISON.md)。
