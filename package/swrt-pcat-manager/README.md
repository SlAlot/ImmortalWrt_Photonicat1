# SWRT 光影猫电源服务

入口：系统 → 光影猫管理；顶部电量按钮也可进入。全新安装默认手动模式，
查看状态不改策略，保存车载 / UPS 或每日计划前需确认。

电源部分使用光影猫官方内核驱动、对应的一代设备树和公开内核接口后台。
版本、实际差异与验证范围见[官方电源对照](../../docs/OFFICIAL-SOURCE-COMPARISON.md)。

- 内核独占 UART4，负责心跳、10 秒看门狗、RTC 与关机握手。
- 后台通过 `/dev/pcat-pm-ctl` 与 power_supply 工作，只开放原有六个电源接口；
  不编译官方模组控制，不干预 QModem 或网络设置。
- 默认电压参数均为 0，保持现场官方系统的 MCU 默认保护；不加入独立充电开关。
- 已知旧出厂配置逐字匹配时才自动迁移，并备份为 `/etc/pcat-manager.conf.pre-kernel-backend`；
  用户自定义电压值保持原样，保留配置升级前仍需自行核对已有电源计划。
- 服务发现官方内核接口缺失或第二个控制者时拒绝启动，不回退裸 UART；普通停止不修改内核看门狗。
- sysfs 读取失败、数值无效或本地状态过期时禁止保存策略；多步骤保存失败会尝试恢复并回读。
- 手动开机、来电开机后的车载倒计时和定时计划遵循官方后台逻辑；手动开机拔线不自动关机。
- 使用设备 `/etc/TZ`；修改时区后重启服务再设置每日计划。

一代供电来源和电量由电压估算，`charging` 仍返回 `null`，界面只显示外部供电 / 电池供电。
没有独立电池温度或电流数据时不填造读数。保留原始源码、版权与许可信息。

原生编译和模拟测试不代表整机充电验收；新内核还需实际检查电池充电、拔线持续运行、
关机及定时唤醒。验证固件验收前不作为正式稳定版发布。
