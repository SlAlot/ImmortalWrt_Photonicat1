## SWRT · 光影猫一代固件

适用于 **Photonicat 1 / RK3568**，支持 **1+8、2+16、4+64 GB**，不适用于二代。作者：**SlAlot**。

### v2.3 更新内容

- 默认使用 Apollo 1.0.0 和 wlmbstart 1.0.0。首页显示蜂窝信号、载波聚合、设备资源和实时流量，自动识别常见蜂窝接口。主题适配桌面、手机和平板。
- 网络面板更新至 1.1.6，增加网络制式设置，并采用与首页一致的信号卡片和适合移动端的顶部切换栏。
- 光影猫管理增加电池容量校准，默认采用原厂读数，可按更换后的电芯容量调整显示估算。光影猫一代的硬件接口无法确认实际充电电流。
- 保留 iStore 商店、QModem Next（Tom 核心）、Docker / Compose、DiskMan、ttyd 和硬盘保活。首次开机自动扩容 eMMC，在线升级保留已扩容的分区边界。

默认管理地址 **192.168.17.1**，账号 **root**，初始密码为空；主机名 **S-Photonicat1**。

### 下载与安装

| 文件 | 内容 |
| --- | --- |
| `immortalwrt-photonicat-1-squashfs-sysupgrade-版本号.img.gz` | SquashFS 固件 |
| `immortalwrt-photonicat-1-ext4-sysupgrade-版本号.img.gz` | ext4 固件 |
| `sha256sums` | SHA-256 校验清单 |

**v1.9 及更早版本升级：**先备份，在“系统 → 备份与升级”上传同类型 `.img.gz`，无需解压，建议不保留配置。不要使用旧 SWRT 在线更新器重试；进入 v2.0 后，后续再使用在线更新。

**v2.0 及以上版本升级：**在“系统 → SWRT 在线更新”依次检查更新、下载并校验、确认升级。更新前下载配置备份，保持当前 SquashFS / ext4 类型。

**首次安装或跨系统切换：**将 `.img.gz` 解压成 `.img`，使用 RKDevTool 和一代 Loader，完整镜像写入地址为 `0x00000000`。首次开机自动扩容可能额外重启一次，请保持供电并等待完成。

硬盘保活只读取数据，不会永久关闭硬盘盒固件的休眠功能，也不能修复供电或线材问题。配置备份不包含 Docker 镜像、容器和数据卷，重要数据另行备份。完整步骤与网卡列表见 [README](https://github.com/SlAlot/ImmortalWrt_Photonicat1#下载与安装)。
