## SWRT · 光影猫一代 v2.1

适用于 **Photonicat 1 / RK3568**，支持 **1+8、2+16、4+64 GB**，不适用于二代。作者：**SlAlot**。

### 版本内容

- 新增“系统 → 硬盘保活”：选择 USB 硬盘，按设置的间隔执行少量直接读取；默认关闭、间隔 60 秒。
- 支持关闭所选硬盘的 USB 自动挂起，停止保活时恢复原策略；不修改 5G 模组或 UAS 驱动。
- 按稳定标识识别硬盘，显示读取时间、次数和错误，避免拔插后因设备名称变化而保活其他硬盘。TF 卡和内置 eMMC 不参与。
- 保留 v2.0 的在线升级修复、官方电源适配及现有网络、容器功能。
- eMMC 首次开机自动扩容，后续升级保留已扩容的分区边界。
- 集成 QModem Next（Tom 核心）、网络面板、iStore 首页与商店、Docker / Compose、DiskMan、ttyd 和光影猫管理。
- 包含 QCA9377、WCN6855、MT7603、MT76x2、MT7921 / MT7922 无线驱动及常用 USB 驱动，软、硬件流量卸载默认开启。

默认管理地址 **192.168.17.1**，账号 **root**，初始密码为空；主机名 **S-Photonicat1**。

### 下载与安装

| 文件 | 内容 |
| --- | --- |
| `immortalwrt-photonicat-1-squashfs-sysupgrade-2.1.img.gz` | SquashFS 固件 |
| `immortalwrt-photonicat-1-ext4-sysupgrade-2.1.img.gz` | ext4 固件 |
| `sha256sums` | SHA-256 校验清单 |

**v1.9 及更早版本升级：**先备份，在“系统 → 备份与升级”上传同类型 `.img.gz`，无需解压，建议不保留配置。不要使用旧 SWRT 在线更新器重试；进入 v2.0 后，后续再使用在线更新。

**v2.0 升级：**在“系统 → SWRT 在线更新”依次检查更新、下载并校验、确认升级。更新前下载配置备份，保持当前 SquashFS / ext4 类型。

**首次安装或跨系统切换：**将 `.img.gz` 解压成 `.img`，使用 RKDevTool 和一代 Loader，完整镜像写入地址为 `0x00000000`。首次开机自动扩容可能额外重启一次，请保持供电并等待完成。

硬盘保活只读取数据，不会永久关闭硬盘盒固件的休眠功能，也不能修复供电或线材问题。配置备份不包含 Docker 镜像、容器和数据卷，重要数据另行备份。完整步骤与网卡列表见 [README](https://github.com/SlAlot/ImmortalWrt_Photonicat1#下载与安装)。
