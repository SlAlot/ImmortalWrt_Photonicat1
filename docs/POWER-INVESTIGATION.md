# 充电与电源管理检查

本次以真机官方系统为基准，先核对官方内核驱动、后台、默认配置和启动指令，再对应移植。
完整源码版本和证据见[官方电源对照](OFFICIAL-SOURCE-COMPARISON.md)。

## 当前处理

- 使用官方内核电源驱动及一代绑定，保持心跳、看门狗、RTC 和关机逻辑配套。
- 后台默认电压参数全为 0，保留 MCU 默认保护；不再沿用旧出厂配置中的 4100 满电覆盖和 3600 模组覆盖。
- 只迁移逐字匹配的旧出厂配置，并保留备份；不强改用户自定义电压或电源计划。
- 保持现有光影猫管理界面、QModem 和网络设置。

## 必须实测的项目

1. 接充电器、保持相近负载，观察电池电压是否逐渐回升；不能只看 Charging 文案或百分比。
2. 手动模式拔下充电线后持续运行，确认由电池接管。
3. 再验证车载倒计时、恢复外部电源取消倒计时，以及正常关机与定时开机。

一代的状态和电量以电压估算，没有公开的充电电流或独立充电开关。
官方说明输入低于 4.9V 时充电可能变慢、低于 4.7V 时停止充电；这是状态解释，
不据此把本次系统差异归因于用户更换了硬件。不会关闭温度、低电压或其他保护来绕过故障。
