# 官方电源方案与 SWRT 适配

适用于光影猫一代 / RK3568。官方构建树同时包含一代与二代，SWRT 只采用匹配一代的驱动、设备树和电源接口。

## 电源链路

- 内核 `photonicat-pm` 独占 UART4，维护心跳、10 秒看门狗、RTC 和关机握手。
- 一代设备树采用 `pm-version = <1>`、115200 串口、官方主电源 GPIO 和辅助供电 gpio-hog，避免重复所有者。
- 后台使用 `/dev/pcat-pm-ctl` 和 power_supply，不直接接管串口；不编译官方模组控制，QModem 负责拨号。
- 九项电压参数默认全为 0，保持 MCU 默认保护。仅迁移逐字匹配的旧出厂配置并备份，用户自定义值不覆盖。
- 电池元数据采用现场官方系统的最小 3560000、最大 4100000 微伏；这些元数据不是充电电压命令。
- 每日计划按本地时间显示，发送 MCU 前转换为 UTC；RPC 参数使用对应的 JSON 数字类型。

## 状态与验证

已核对官方与 SWRT 的启动载荷、内核接口、设备树和 GPIO 所有权，并验证真机启动及三种模式的保存、读回和互斥切换。模拟与状态检查不能替代完整充放电和关机唤醒周期验证。

一代电量按电压估算，没有公开的独立充电开关或充电电流接口；界面不把供电在位当作实测充电电流，也不使用二代命令控制一代。日常操作见[电源服务说明](../package/swrt-pcat-manager/README.md)。
